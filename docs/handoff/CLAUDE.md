# 참고 원본 — 개발 경위 (`REFERENCE-ONLY`)

> **역할** 이전 세션의 인수인계 기록이다
> **상태** `REFERENCE-ONLY` — **정본 아님. 인용하지 말 것**
> **읽을 절** 없음 — 하네스 라우팅 대상이 아니다
> **정본** 설계는 `docs/spec/` · 구조는 `SOT.md` · 상태는 `docs/status.md`

## 왜 이 표시가 필요한가

여기 있는 문서는 **spec v0.2 가 이미 소화해서 결정으로 옮긴 입력 자료**다.
표시가 없으면 협업자가 정본으로 착각하고 인용하게 되고, 그러면 이미 뒤집힌 판단이
논문·제안서로 나간다. 실제로 그런 사례가 있었다 — `SESSION_HANDOFF` 의
「`/dev/dri` 가 없어 EGL 오프스크린 불가」 진단은 나중에 정정됐다 (`README.md` 참조).

## 언제 여나

- spec 의 어떤 결정이 **왜** 그렇게 됐는지 출처를 추적할 때
- spec 이 놓친 원본 내용이 있는지 확인할 때 (있으면 spec 에 반영하는 것이 먼저다)

그 외에는 열지 않는다.
