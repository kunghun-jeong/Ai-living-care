# 표준 산출물 (I-D · 기고문)

> **역할** IETF/IRTF I-D 초안, ITU-T·IEC 기고문의 원고가 사는 곳
> **상태** Phase 0 · **미작성** — 자리만 있다
> **읽을 절** spec **§11.1**(`S-*` 정본). **그 외 절은 열지 않는다** — spec 은 제안서·표준의 기준 문서가 아니다
> **정본** 구조는 `SOT.md` §2 · 표준화 항목은 spec §11.1 · 수치와 한정어는 `docs/status.md`

표준화 항목 `S-1`~`S-7` 의 **정의**는 spec §11.1 이 정본이고, 여기에는 그 항목을
기구 서식으로 옮긴 **원고**가 온다. 항목을 새로 만들거나 이름을 바꾸면 spec §11.1 을
먼저 고치고 여기 원고를 따라 고친다 — 반대 방향은 갈라짐의 시작이다.

`S-*` 하나당 파일 하나를 원칙으로 한다 (`draft-<기구>-<항목>-NN.md`).

**수치를 인용할 때는 출처와 한정어를 함께 적는다** (`docs/conventions.md` §11).
원고가 저장소 밖에서 만들어지면 spec ↔ 원고 갈라짐을 아무도 보지 못한다 —
그것이 이 디렉터리를 둔 이유다.
