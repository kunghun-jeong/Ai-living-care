> **한 줄이면 된다.** 결정을 내렸으면 아래 표 맨 위에 한 행. 근거가 길면 그 자리 `CLAUDE.md` 에 쓴다.
> 세션 진행 기록·작업 경위는 쓰지 않는다 — `git log` 가 그것이다.

## 정본은 여기가 아니다

| 무엇 | 정본 | 이 문서의 역할 |
|---|---|---|
| 설계 결정 `D-1`~`D-8` | spec §0.2 | 없음 |
| 구조·경계 결정 `D-9`~`D-18` | `SOT.md` §6 | 없음 |
| 결함 `F-*` · 갭 `G-*` · 선결 `U-*` | `docs/status.md` | 없음 |
| 작업 절차 | `docs/harness.md` · `docs/doc-map.md` | 없음 |
| **그 밖의 결정** | **이 문서** | **정본** |

구조나 설계를 바꾸는 결정이면 여기 한 줄을 쓰고 **정본에도 반영한다.** 반영하지 않으면
정본이 파생물보다 낡는다 — 실제로 그렇게 됐었다 (F-20).
