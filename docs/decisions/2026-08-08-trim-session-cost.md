# 2026-08-08 · 세션 비용을 덜어낸다 — 참조표와 잡항목을 자동 로딩 밖으로

> **정본 반영** `docs/canon.md` · `docs/doc-map.md` §3 · `docs/status.md` · `docs/status-defects.md` · `docs/CLAUDE.md`

매 세션 자동 로딩되는 네 문서만이 **진짜 비용**이다. 나머지는 열 때만 내는 재고다
(검사 코드 1,293줄은 사람이 안 읽고, 컴포넌트 문서는 자기 것 평균 30줄만 읽는다).
그 비용에서 **참조용**인 것을 뺐다 — 셋 다 「작업 시작점」이 아니었다.

| 뺀 것 | 어디로 | 왜 |
|---|---|---|
| `doc-map` §3 정본 소유권 22행 | `docs/canon.md` | 「무엇을 열까」가 아니라 **「이 사실을 어디에 쓸까」**다. 기록 직전에 한 번 연다 |
| `status.md` `TODO(확인 필요)` | `docs/status-defects.md` | 확인해야 할 잡항목이 매 세션 실릴 이유가 없다 |
| `status.md` 「결함 이력」 안내 10줄 | 2줄로 | 「전문은 저기 있다」에 10줄을 쓰고 있었다 |

**`doc-map` §3 은 지우지 않고 리다이렉트 스텁으로 남겼다** — 저장소 14곳이 「doc-map §3」으로
그 표를 가리키고 있어서, 없애면 그 참조들이 전부 허공을 가리킨다. 스텁이 받아 넘긴다.

잃은 것은 없다. 셋 다 gateway 뒤에서 필요할 때 열린다.

「−48」로 적었는데 규약 증가분을 빼먹은 수치다 — **정본은 이 표다.**
