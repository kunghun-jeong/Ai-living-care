# 2026-08-08 · `상태` 줄에 「지금 무엇으로」를 넣는다 — 장치 0개로 상·하위를 잇는다

> **정본 반영** `docs/harness.md` §3 · `CONTRIBUTING.md` · `docs/harness/docs-and-structure.md`

세 가지 요구가 있었다 — ① 논문 담당자가 새 세션에서 **최신 구현을 반영해** 쓰기, ② 작성 중인
원고를 **탐지해서** 이어 고치기, ③ 하위가 세부 선택을 바꾸면 **상위가 포착**하기.

**셋 다 새 장치가 필요 없었다.** `상태` 줄은 이미 있고, `make status` 가 이미 수확하고,
훅이 이미 넛지한다. 빠진 것은 **그 줄에 무엇을 적는가**뿐이었다.

지금까지 `상태` 줄은 Phase 와 ID(`F`·`G`·`0-*`)만 담았다 — **「얼마나 갔나」는 알려주지만
「무엇으로 만들었나」는 알려주지 않는다.** 그래서 `LSTM → BERT`, `Llama single-prompt →
GPT-4o few-shot` 같은 전환이 상위에 도달하지 않았다. 논문 담당자는 옛 기법으로 쓰게 된다.

```
✅  Phase 1 · 구현 중 · LM encoder(BERT-base, LSTM 에서 전환) · 작업 0-5
❌  Phase 1 · 진행 중
```

**기계가 만들 수 없는 유일한 조각이다.** 무엇이 무엇을 대체했는지 아는 건 바꾼 사람뿐이고,
그래서 이건 검사가 아니라 규약이다. 검사를 하나도 늘리지 않았다.
