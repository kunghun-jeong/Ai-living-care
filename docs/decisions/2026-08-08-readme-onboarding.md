# 2026-08-08 · 팀 온보딩 한 장을 README 에 둔다

> **정본 반영** `README.md`

새 협업자가 처음 여는 곳은 GitHub 랜딩 페이지, 즉 `README.md` 다. 그런데 그 문서는
**「작업하러 오셨다면 여기가 아닙니다」**로 시작해 `CLAUDE.md` 와 `CONTRIBUTING.md` 로
돌려보내고 있었다 — 합류 첫 화면이 **리다이렉트 두 번**이었다.

온보딩 일곱 조각을 한 절로 모았다: 최초 1회 · 세션마다 한 번 · 일할 때 다섯 줄 ·
병렬로 부딪히지 않는 법 · 남의 트리 · 브랜치 · 그 밖에 열 문서.

**복제는 늘리지 않았다.** 각 항목은 정본을 링크로 가리키고 요약만 둔다
(`docs/canon.md` 의 「실행 명령은 해당 디렉터리 `CLAUDE.md` 가 정본, 루트 `CLAUDE.md`·
`README` 는 복제 허용」에 이미 등재된 범위다). 그리고 「빠른 시작」에 있던 `make hooks`
중복을 지우고 온보딩으로 링크했다 — 같은 명령이 두 곳에 있으면 한쪽이 낡는다.

커버리지 93.6% 옆에 **「기하 시뮬레이션 결과이지 실측이 아니다」** 한정어를 붙였다.
README 는 인용이 가장 많이 새어 나가는 문서인데 그 자리에 한정어가 없었다 (`F-17`).
