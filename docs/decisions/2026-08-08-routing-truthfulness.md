라우팅 문서 넷이 서로 다른 시대의 규범을 말하고 있었다. 셋을 정리했다.

**`docs/CLAUDE.md` 「읽는 순서 1~6」 삭제.** `SOT.md` → spec §1~§5 → §10 → `handoff/` 를
**통독**하라는 3계층 문서(2026-08-06) 이전의 규범이었다. `docs/` 를 만지러 온 세션이 여는
첫 문서라, 남겨 두면 라우팅 예산을 실측 645줄에서 1,280줄로 되돌린다. 무엇을 열지는
`docs/doc-map.md` §1 이 정한다고만 남겼다.

**하네스 장치 표를 실재하는 `A1`~`A9` 로 교체.** 11행 중 7행이 `decisions.md` 에서 이미
폐기한 보증(`DA-3`·`4`·`5`·`6`·`8`·`10`·`11`)이었고, 실재하는 `A5`(안전 인계)·`A6`
(`.gitignore`)는 표에 없었다. 같은 파일 39행이 **"통과하는 것처럼 보이는 검사가 없는
검사보다 나쁘다"** 고 쓰는데 그 두 칸 아래에 없는 검사가 일곱 있었다. 못 보는 것 셋
(A2 는 이름 집합만 · 소유 경계 기계 강제 없음 · ID 실재 미검사)을 경고로 명시했다.

**`V-1`~`V-5` 인용 제거.** 정의처로 지목된 `docs/harness.md` 에 그 ID 가 없다 —
2026-08-06 하네스 축소 때 사라졌는데 인용 둘이 살아남았고, 하나는 **매 세션 자동 로딩되는**
`docs/status.md` 에 있었다. 옛 `DA-5`(ID 실재 검사) 포기의 첫 실증 사례다.
`decisions.md` 는 그 포기에 대해 "아직 사고가 없다"고 적고 있었다 — 이미 있었다.

**`HD-1`(수치 표기 4분류)을 `docs/papers/CLAUDE.md` 로 복제.** 정본은 하네스 노트인데,

자리의 규약이 그것을 가장 필요로 하는 사람에게 도달하지 않고 있었다. 복제 허용을
`doc-map` §3 에 등재했다.

**`doc-map` §1 스키마 행의 절 지목 정정.** `spec §4`(196줄)라 적혀 있었으나 각 컴포넌트
