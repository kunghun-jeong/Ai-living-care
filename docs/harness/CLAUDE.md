# 하네스 노트

> **역할** 영역별 참고 노트 — **관문이 아니다.** 그 영역을 처음 건드릴 때 한 번 읽는다
> **상태** 상시 · 6종
> **읽을 절** 없음 — 절차는 `docs/harness.md`, 무엇을 열지는 `docs/doc-map.md` §1
> **정본** 구조 `SOT.md` · 작업 절차 `docs/harness.md` · 각 노트의 `H*-` 체크는 그 노트

| 노트 | 대상 | 로컬 ID |
|---|---|---|
| `mcp.md` | MCP tool · A2A / IF-4 | `HM-*` |
| `worker-agent.md` | Worker 규범(`CLAUDE.md`) 또는 담당자 본인 | `HW-*` |
| `manager-ai.md` | Manager 신규 구현 | `HG-*` |
| `simulation.md` | Gazebo · Nav2 · 순찰 · 맵 | `HS-*` |
| `docs-and-structure.md` | 문서 · 디렉터리 구조 · 수치 표기 규약 | `HD-*` |

**코드를 며칠 읽어야 알 수 있는 함정만 모은다.** 절차·관문·등급은 여기 두지 않는다 —
그것은 `docs/harness.md` 네 단계가 전부다.

`H*-` 는 이 디렉터리 **전용**이다 (D-15). 전역 `P-*`·`S-*`·`AR-*` 와 단어 경계가 갈려야
"P-4를 지켰나"라는 문장의 의미가 결정된다.
