# 하네스 — 문서 · 구조 · 스펙

> 대상: `CLAUDE.md`(전부), `SOT.md`, `docs/**`, `sot_audit.py`, 디렉터리 이동·신설
>
> 이 문서는 **관문이 아니라 참고 노트**다. 이 영역을 처음 건드릴 때 한 번 읽는다.
> 작업 절차는 `docs/harness.md` — §0 세션 시작 · 읽기 · 앵커 갱신 · 결정 파일 하나가 전부다.

## 0. 가장 중요한 규칙

### `CLAUDE.md`와 `docs/**`는 **사람이 직접 유지한다.** 생성기를 쓰지 않는다.

`sot_migrate.py`와 `sot_preserve.py`는 **폐기됐다** (2026-08-06 결정).
이 스크립트들은 42개 `CLAUDE.md`를 내장 문자열 딕셔너리에서 **전면 덮어쓰기** 하는데,
그 템플릿에 구 경로가 박혀 있어 실행하면 방금 고친 문서가 되돌아간다.
**문서 결함의 단일 최대 원인이었다.**

```
❌ python3 sot_migrate.py claudemd     # 실행 금지 — 문서를 되돌린다
❌ python3 sot_preserve.py docs        # 실행 금지 — 멱등하지 않다
✅ 편집기로 .md 를 직접 고친다
```

## 2. 알아 둘 것 (함정)

```bash
python3 sot_audit.py      # 구조 (AR-1~AR-10)
python3 anchor.py      # 문서 정합성 — 아래 검사가 전부 여기 들어 있다
```

**둘 다 통과해야 커밋한다.** 예전에 이 자리에 있던 셸 검사 두 개는 폐기했다 —
하나는 ` ```bash ` 펜스만 스캔해서 루트 `CLAUDE.md`(인라인 불릿)에서 **0개 경로를 검사**했고,
다른 하나는 `! A | B || echo` 구조라 **무슨 일이 있어도 exit 0**이었다.
**통과하는 것처럼 보이는 검사가 없는 검사보다 나쁘다.**

**아래가 `anchor.py` 가 실제로 하는 전부다.** 여기 없는 것은 **아무도 안 본다** —
`docs/decisions.md` 「감사 폐기로 포기한 보증」이 무엇을 포기했는지 갖고 있다.

| 검사 | 무엇을 본다 | 등급 |

## 4. 문서를 쓸 때

- **사실만 쓴다.** 코드에서 확인하지 못한 것은 `TODO(확인 필요)`로 남기고 추측으로 채우지 않는다.
- **"동작한다"와 "동작할 것이다"를 구분한다.** 실행해서 확인한 것만 동작한다고 쓴다.
- **한정어를 지운 채 인용하지 않는다.**
- 루트 `CLAUDE.md`는 **50줄 이내**를 유지한다. 늘어나면 `docs/` 아래로 분리한다.
- 컴포넌트 `CLAUDE.md`는 헤더 외에 **최소 하나의 실행 가능한 항목**(계약 시그니처 / 스키마 /
  갭 ID / 작업 번호)을 갖는다. 헤더만 있으면 그 문서는 없는 것과 같다.
- **`상태` 줄에 「지금 무엇으로」를 넣는다** — 기법·모델·전환 이력 (`docs/harness.md` §3).
  Phase 와 ID 만 있으면 「얼마나 갔나」만 알고 「무엇으로 만들었나」는 모른다.
