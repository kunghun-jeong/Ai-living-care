> **역할** IETF-125/126 승계 판정 원본 — **참고 전용, 결정이 아니다**
> **상태** 참고 전용 · 판정이 spec 에 미반영
> **읽을 절** 없음 — 인용은 spec **§11.1**(`S-*` 정본)까지
> **정본** 여기가 아니다. 표준화 항목의 정본은 spec §11.1 · 구조는 `SOT.md`

**여기 있는 판정을 근거로 문서를 쓰지 않는다.** spec 에 반영되지 않은 상태이고,
반영 여부를 정하는 것이 먼저다. 반영하기로 했다면 `docs/decisions/CLAUDE.md` 절차로 결정 파일을
만들고 spec §11.1과 `정본 반영`에 적은 활성 복제본을 같은 변경에서 고친다 — 그 뒤로는 spec 이 정본이다.

`docs/context/` · `docs/handoff/` 와 같은 지위다 (`REFERENCE-ONLY`).
