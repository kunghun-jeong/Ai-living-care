# 논문 원고

> **역할** 매거진 논문·학술 원고가 사는 곳
> **상태** Phase 0 · **미작성** — 자리만 있다
> **읽을 절** spec **§11**(표준화 항목) — 구성 초안은 §11.3
> **정본** 구조는 `SOT.md` §2 · 설계는 spec · 수치는 **실행 출력**(`docs/status.md` 의 한정어를 그대로 옮긴다)

`docs/doc-map.md` §1 「매거진 논문 작성」 이 무엇을 열지 라우팅한다.

**수치는 여기서 만들지 않는다.** 커버리지·지연·rate 는 실행 출력이 정본이고,
`docs/status.md` 가 한정어와 함께 갖고 있다. 원고가 그 한정어를 떼면
(예: "2 m² 이상 사각지대 0" → "사각지대 0") 반박 가능한 문장이 된다.

## 수치 표기 — 넷 중 하나로 쓴다

> 정본은 `docs/harness/docs-and-structure.md` `HD-1`. **여기에 복제한 이유는 원고 쓰는
> 사람이 문서·구조 하네스 노트를 열지 않기 때문이다** (`docs/doc-map.md` §3 에 복제 허용 등재).
> **기계가 못 잡는 항목이다** — 감사 초록이 이 표를 지켜 주지 않는다.

| 표기 | 쓰는 법 |
|---|---|
| 재현 가능 | "기하 시뮬레이션 기준 93.6% (`patrol_sim.py` 실행 결과)" |
| 1회 실측 | "`turtlebot3_world` 에서 1회 측정, `/odom` (0,0)→(0.764, 0.009)" |
| 미측정 가정 | "`CAM_RANGE = 4.0 m` — **미측정 가정**" |
| 외부 인용 | "Duan & Lu, arXiv:2508.15819" |

**상위 문서의 수치를 인용할 때 원문의 한정어를 함께 가져온다.** 93.6% 는 **기하
시뮬레이션 결과**이지 실측이 아니고, 사각지대 0 은 **2 m² 이상** 기준이다 (F-17).
