# 논문 원고

> **역할** 매거진 논문·학술 원고가 사는 곳
> **상태** Phase 0 · **미작성** — 자리만 있다
> **읽을 절** spec **§11**(표준화 항목) — 구성 초안은 §11.3
> **정본** 구조는 `SOT.md` §2 · 설계는 spec · 수치는 **실행 출력**(`docs/status.md` 의 한정어를 그대로 옮긴다)

`docs/doc-map.md` §1 「매거진 논문 작성」 이 무엇을 열지 라우팅한다.

**수치는 여기서 만들지 않는다.** 커버리지·지연·rate 는 실행 출력이 정본이고,
`docs/status.md` 가 한정어와 함께 갖고 있다. 원고가 그 한정어를 떼면
(예: "2 m² 이상 사각지대 0" → "사각지대 0") 반박 가능한 문장이 된다.
